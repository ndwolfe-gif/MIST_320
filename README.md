# Build Me Up: Field Operations & Change Management Portal

## 1. Project Overview
The Build Me Up portal is a cloud-based Information Systems solution designed for the Architecture, Engineering & Construction (AEC) industry. It addresses critical operational bottlenecks caused by miscommunication between job-site field engineers and central office project managers. By replacing physical paper logs and unindexed messaging threads with a centralized, real-time platform, the system ensures physical job-site progress is accurately tracked against financial budgets in real time.

## 2. Project Scope & Objectives
### Project Scope
* **In-Scope:**
  * Mobile-responsive web application for field engineers to upload daily site logs, track safety incidents, flag blueprint modifications, and submit change requests.
  * Centralized dashboard for office project managers to review, approve, and link change orders directly to project budgets.
  * Real-time cloud database and file storage integration.
* **Out-of-Scope:**
  * Replacement of enterprise accounting ledger software (the portal integrates with financial systems rather than replacing them).
  * Procurement of physical field hardware or tablets.

### Measurable Objectives
* Reduce average change-order approval cycle time from 5 days to under 24 hours within 3 months of deployment.
* Eliminate 100% of physical paper log tracking across pilot construction sites.
* Achieve seamless real-time cost visibility, mapping field progress updates to budget alterations with zero data-entry lag.
